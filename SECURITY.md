# Security Policy

## Supported Versions

FrutigerOS is pre-alpha. There are no stable releases yet.

| Version | Supported |
|---------|-----------|
| main    | ✅ Yes     |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Email: security@frutigeros.dev (placeholder — update before launch)

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 72 hours and aim to patch critical issues within 7 days.

## Scope

In scope:
- AeroWM compositor
- AeroInstaller (disk operations, privilege escalation)
- AeroShell
- Native applications

Out of scope:
- Arch Linux base system (report to Arch Linux upstream)
- Third-party packages
