Getting started

Build every Rust component, run the tests, and start AeroWM inside your current desktop session.

Repository layout. AeroWM, AeroShell and AeroInstaller are standalone Cargo crates. The nine applications form a workspace under aero-apps/. There is no root workspace, so run Cargo from the crate directory.

Prerequisites

The development environment targets Arch Linux. Install the toolchain and the native libraries used by Smithay, Wayland clients and the panel renderer.

sudo pacman -S --needed base-devel rustup pkgconf \
  wayland wayland-protocols libxkbcommon mesa \
  libinput libseat libdisplay-info libudev-zero \
  fontconfig freetype2

rustup default stable

Rust 1.75 or newer is required. The crates use Smithay 0.3, tiny-skia and wayland-client.

Fetch the source

git clone https://github.com/frutigeros/frutigeros.git
cd frutigeros

Build and test

Run each crate independently. Formatting must be clean before a pull request is merged.

# AeroWM compositor
cd aerowm
cargo fmt --check
cargo test

# AeroShell panel
cd ../aeroshell
cargo fmt --check
cargo test

# AeroInstaller
cd ../aero-installer
cargo fmt --check
cargo test

# Native applications (workspace)
cd ../aero-apps
cargo fmt --all --check
cargo test --workspace

At the time of writing the suites report:

CrateTestsNotes
aerowm23config, input, workspace, effects, render
aeroshell23panel layout/render, glyphs, launcher, notifications
aero-installer18steps, disk planning, command planner
aero-apps32nine application crates

Run AeroWM

AeroWM currently uses the Smithay winit backend: it opens a window inside an existing X11 or Wayland session. Native DRM/KMS startup is not implemented yet. 

cd aerowm
cargo run

The log prints the Wayland socket it created, for example:

[INFO] WAYLAND_DISPLAY=wayland-1
[INFO] Clients can connect: WAYLAND_DISPLAY=wayland-1 <app>

Run AeroShell

In a second terminal, point AeroShell at that socket. The panel creates an xdg toplevel with app_id=frutigeros-aeropanel; AeroWM recognises it and pins it to the bottom of the screen.

cd aeroshell
WAYLAND_DISPLAY=wayland-1 cargo run

You should see a deep-ocean glass bar with a start orb, four workspace dots, a clock and tray glyphs.
