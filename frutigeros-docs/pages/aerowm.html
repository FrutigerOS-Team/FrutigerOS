AeroWM

A Smithay-based Wayland compositor written in Rust. It owns the display socket, maps xdg-shell toplevels, manages floating workspaces and hosts the AeroShell panel.

Backend status. AeroWM runs on the Smithay winit backend (a window inside X11/Wayland). The udev/DRM backend for bare-metal startup is not implemented. Shader sources for glass and shadows exist but are not wired into the render path yet.

Surface lifecycle

  1. An xdg_toplevel is created by a client.
  2. sync_windows() reads app_id and title from surface data.
  3. Ordinary windows are inserted into the active workspace with a cascade position.
  4. A surface with app_id = "frutigeros-aeropanel" is promoted to panel: it is removed from workspace management, pinned full-width at the bottom, and reconfigured to screen_width × panel_height.
  5. Dead surfaces and surfaces with a removed buffer are dropped on the next sync.

Panel detection

The panel is detected during the periodic sync_windows() pass, not in the commit hook. The first client frame may briefly use the initial configure size before the panel-specific configure arrives.

const PANEL_APP_ID: &str = "frutigeros-aeropanel";

let is_panel = app_id.as_deref() == Some(PANEL_APP_ID);
if is_panel && !win.is_panel {
    self.configure_panel(key);
}

Rendering

The compositor clears to deep ocean (#063B5C), imports pending SHM buffers into GLES2 textures, draws the active workspace in stack order, then draws panels last so they sit above windows. Frame callbacks are sent after presentation so clients can throttle.

Pointer and focus

Absolute pointer motion is forwarded to the focused surface. Hit-testing walks the active workspace stack from top to bottom and then checks panels, which sit above normal windows. Clicking a window focuses and raises it; button events are forwarded to the surface under the cursor.

Configuration

AeroWM reads ~/.config/aerowm/config.toml (or $XDG_CONFIG_HOME/aerowm/config.toml) and falls back to defaults on any error.

[general]
backend = "winit"
xwayland = false

[appearance]
corner_radius   = 12
blur_strength   = 20
glass_opacity   = 0.82
border_active   = "#00AEEFcc"
border_inactive = "#7DDCFF44"
animation_speed = 1.0
shadow_blur     = 24
shadow_opacity  = 0.40
panel_height    = 48

[workspaces]
count          = 4
default_layout = "floating"

[keybindings]
modifier = "super"
Not yet implemented: interactive move/resize, shader-based blur and rounded corners, animation applied to real surfaces, tiling layouts, XWayland, and the udev/DRM backend. The config keys for these are accepted but currently unused.
