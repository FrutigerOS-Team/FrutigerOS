The Heart of FrutigerOS

AeroWM

A custom Wayland compositor built entirely in Rust using the Smithay framework. AeroWM is not a fork, not a config file. It is a real compositor written from scratch, with FrutigerOS's visual identity baked in at the lowest level.

  • ✓ Wayland compositor with XDG shell support
  • ✓ Workspace management with focus cycling
  • ✓ Aero Glass material system (blur, transparency, gradients)
  • ✓ Smooth spring-based animations
  • ✓ Floating, tiling, and hybrid layout modes
  • ✓ TOML configuration — no scripting languages required
Phase 2 implemented · 30 unit tests passing
~/.config/aerowm/config.toml 
# AeroWM configuration

[appearance]
corner_radius  = 12
blur_strength  = 20
glass_opacity  = 0.82
border_active  = "#00AEEFcc"
animation_speed = 1.0

[workspaces]
count          = 4
default_layout = "floating"

[keybindings]
modifier       = "super"
